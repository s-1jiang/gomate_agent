`validate_draft` 只执行明确列出的基础约束。其 `valid` 表示这些检查通过，不能作为完整出游计划的最终发布许可。

后台运行器已连接 DeepSeek 文本适配器。收到消息后检索当前用户及会话可见资料，调用模型，验证租约后保存回复与来源。没有密钥时明确返回 `PROVIDER_NOT_CONFIGURED`；不会生成伪造地图或已校验行程。

前端位于 `frontend/`，完成 Run 轮询后自动读取真实回复；来源列表只来自服务端召回。当前采用本地关键词检索，尚非完整向量 RAG。详见 [聊天与来源说明](CHAT_AND_RAG.md)。Docker 使用独立命名卷，不自动迁移本机已有数据库。

进程内预算不是跨进程安全边界；`ToolContext` 数据类不等于 MCP 身份验证。私有 MCP 工具必须在签名校验与持久化网关完成后才开放。

`requirements.lock` 是本次 Windows Python 3.13 的依赖快照。CI 配置覆盖 Linux Python 3.11 和 Windows Python 3.13，远程 CI 成功与否需以实际运行结果为准。
