# GoMate Web

React + TypeScript + Vite。所有请求走同源 `/api/v1`，开发代理在 `vite.config.ts`，容器代理在 `nginx.conf`。

```powershell
npm.cmd ci
npm.cmd run dev
```

默认 http://127.0.0.1:5173，后端默认 http://127.0.0.1:8000。需要改后端地址时设置仅开发服务器使用的 `GOMATE_API_TARGET`。

```powershell
npm.cmd test
npm.cmd run build
```

- 页面支持注册登录、城市选择、草稿、历史会话、搜索、删除确认、保存消息、Run 轮询与取消。
- “保持登录”默认勾选，使用后端 HttpOnly Cookie，默认 30 天；重新打开页面会验证并恢复登录。取消勾选时仅在当前标签页保存会话 Token。
- “记住账号密码”默认勾选：账号名称与选项保存在 localStorage，密码只交给浏览器密码管理器保存；需按浏览器提示确认，是否保存及自动填充由浏览器设置控制。
- 退出登录会撤销服务端凭证并清除 Cookie/标签页会话；过期后重新登录。退出失败会明确提示，不会假装已完成。
- API 失败保留草稿，重试同一条消息复用幂等键。
- 快速切换会话时放弃旧请求，避免晚到的历史覆盖当前页面。
- 文字聊天在 Run 终态后自动读取真实回复；失败显示简短的重试提示，不展示供应商或密钥诊断。
- 按会话跟踪后台任务；切换时不取消生成，重新打开/刷新从服务端最新 Run 恢复，临时断网后继续轮询；不再设置130秒前端停止上限。
- “知识库”支持文本导入和可见范围选择；回复下展示服务端检索来源、行号和原文，区分已引用与只召回。
- 右侧支持城市/关键词地点搜索；按需加载高德 JS 地图，用已审查 POI 的 GCJ-02 坐标绘制标记，保留来源和地点链接。
- 任务分发、审查记录及供应商编号仅保留在后端；未通过审查的候选不进入地点列表。原生 JS 安全密钥只在后端固定代理中使用。
- 游玩需求按同一持久化 JSON 渲染时间轴、交通/缓冲、每站时长与建议玩法、来源和回答内地图。省略假设列表、重复概述及内部校验说明；实用信息需有对应地点的网页来源，开放和预约统一简短提醒。无底图时仍可查看位置示意；缺失路线不画直线。
- 公共交通可衔接经过查询的短途步行，摘要和每段交通均按实际 mode 展示。交通服务失败时提示稍后重试，具体诊断保留在后台。
- 普通周边推荐按校区/区域展示一组餐饮与活动、来源链接及可用的步行衔接；用户选择校区后继续本会话的任务。未要求具体时间表时不强行补齐日期、口味等可选信息。
- 推荐数量由模型依据用户要求和实际候选判断，页面展示完整的已审查清单；“多推荐几家”接续上一轮主题。店铺比较作为备选列表展示，不强制串成路线。
- 私有资料检索仍为本地关键词匹配；向量召回/重排、天气、营业窗口与完整预算求解尚未接入。
- 不在前端环境变量中放 DeepSeek 或高德 Web 服务密钥。静态构建不需要任何外部凭证。

容器启动方式见 `../docs/DOCKER.md`。
